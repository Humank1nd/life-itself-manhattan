## New original, provider-neutral software

- `src/conditioning-envelope.js` validates the producer schema
  `life-itself-cloud-capture/1.0.0` and builds
  `life-itself-conditioning-envelope/1.0.0` from *actual* hosted capture
  metadata. No proprietary weights, inference client, provider-dependent camera transforms,
  secret references or pixel bytes in this module.
- `scripts/verify-conditioning-envelope.mjs` runs only on GitHub-hosted Actions.
  It refuses a non-hosted runner and output paths outside ephemeral
  `runner.temp`. It verifies both input JSON source hashes and **all nine
  actual PNG file bytes/hashes**, validates the source-version crosswalk and
  the **explicit different** Phase 015 capture raster/camera/depth contract.
  Then writes `conditioning-envelope-v1.json` into the same short-lived
  cloud artifact directory.
- `.github/workflows/cloud-times-square-capture.yml` executes capture →
  validated envelope → upload, failing the upload if the strict conditioning
  gate fails. GitHub Actions artifact retention stays **3 days**.

The envelope has provenance hashes for the city manifest, the exact building
version snapshot, and the capture manifest; camera extrinsics (ENU positions
and look targets), intrinsics, image origin; three referenced RGB/depth/BIN
passes; a 622-entry BIN/version crosswalk; explicit per-pass format/units;
rights and historical truth rails; plus `provider.kind='none'`,
`inferenceExecuted=false`. It is **metadata only** and is not a training
authorization or an image generated by a world model.

### Important limits

- The RGB24 linear-camera-Z depth pass has background black; near-plane
  geometry can also encode black. Consumers must use the **nonzero
  building-ID mask** before interpreting any depth pixel.
- RGB building indices are local to the capture manifest. The stable
  identity is `BIN+versionId`, not RGB color or pixel coordinates.
- The 640×360/62° cloud camera path is *different* from the 512×512/55°
  Phase 014 pilot. The previous photo camera is not surveyed; any cross-pilot
  pixel comparison requires explicit camera re-projection and semantic
  depth calibration. This PR deliberately makes no such conversion.
- A same-host exact-frame SHA check verifies source-to-envelope integrity,
  not scientific geometric accuracy or cross-GPU identical rasterization.
- Model rights must be audited against exact code/weight/third-party notices.
  Training and model effects remain disallowed pending distinct approval.
- No paid GPU, real-time XR model, historical animation, data download,
  persistent local output store or AWS instance is created.

## CI acceptance

1. Hosted capture creates 9 × 640×360 real RGB/depth/BIN PNGs.
2. All frame byte lengths, PNG signatures and SHA-256s match the source
   capture manifest and both source JSON files match their recorded hashes.
3. The full 622-entry crosswalk matches the current authoritative version
   list, and 25 observed IDs resolve to source versions (actual count may
   change with an explicitly versioned future capture).
4. Deterministic envelope produced without copying images into GitHub source.
5. Negative tests reject: 2005 relabeling, invented geometry/camera pose,
   unauthorized training, claimed model execution, wrong resolution/FOV/depth
   encoding, wrong BIN/version/visible ID, path traversal/duplicate pass,
   incorrect source hashes, tampered PNG bytes and modified manifest bytes.
6. Cloud artifact includes `conditioning-envelope-v1.json` and retains
   source RGB/depth/ID images for three days, no local Houston builds.
7. CI passing is **technical gate acceptance**; PR remains draft until
   reviewed and accepted by founder. No inference claim.
