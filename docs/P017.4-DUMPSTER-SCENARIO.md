**Status:** TEST-DESIGN ONLY. No claim of implemented affordance code, validated biology, or passing tests.
**Branch:** PR #35 draft. Read [P017.4 biology calibration guardrails](./P017.4-BIOLOGY-CALIBRATION.md) before changing executable code.

## Priority: scientific provenance first, scenario fixtures second

Every biological parameter must carry `status` and provenance:
- `MEASURED`: a value and uncertainty measured in the cited study, with species/strain, age, method, environment, units, and source.
- `DERIVED`: computed from measured variables with documented transformation and propagated uncertainty.
- `PROVISIONAL`: model hypothesis not fitted or validated for this population.
- `TEST_ONLY`: synthetic values that assert engineering behavior. **Never** interpret them as wild-rat estimates.

Recording fields: `parameter`, `value`, `unit`, `status`, `population`, `conditions`, `source`, `transform`, `uncertainty`, `usedBy`.

## First deterministic alley fixture: TEST_ONLY

**Objects:** `dumpster-1` associated with `deli-1` food patch.

**Actors:** `rat-A` and `rat-B`; known alive and placed at verified reachable contact positions. Rat A starts with a higher hunger deficit than Rat B. All synthetic coordinates/motives are TEST_ONLY and must be tagged in fixture code.

**Resource:** A small *synthetic* stock of `0.006 kg` in the ecology patch. The test deliberately assumes its synthetic fresh stock is fully edible; this assumption is **TEST_ONLY** and prohibited for real dumpster input without an edible-food model. Rat A requests `0.006 kg` (also TEST_ONLY). These numbers test exact depletion and serial contention, not daily intake or typical bite mass.

**Sequence:**
1. Snapshot a valid advertisement. Record the explicit `0.006 kg` evidence as a test value, separately from the computed forage-attraction score.
2. Score executable scavenging against other candidates, with finite deterministic factors. Keep a non-executable investigation candidate uncommittable.
3. Validate live actor and geometry, fresh-stock availability and causal uniqueness; commit via existing P017 contract.
4. Apply once using the guarded `graze()` path and ensure `eatenKg` and conservation accounts reflect exactly `0.006 kg`.
5. In the **same tick**, Rat B independently observes the **updated zero-stock** patch and cannot consume the previously advertised stock.
6. Re-apply an identical event and attempt a stale rival commit: both fail without additional mass change.
7. Verify decision/event/receipt references, StateJournal chain, checkpoint restore, stable decisions and no duplicate consumption; explicitly report any crash-atomicity gaps.

**Stop condition:** If collision geometry, edible-stock semantics, journal integration or atomic effect application are not yet implemented, report the blocked stage; do not fabricate passing results. A pure ad/scoring unit test is not a substitute for live commit/apply/recovery.
